# Miniräknare

En enkel miniräknare byggd med HTML, CSS och JavaScript – körs direkt i webbläsaren, inga beroenden.

## Funktioner

- De fyra räknesätten samt procent (`%`) och rest (`%`)
- Korrekt prioriteringsordning (`3 + 4 × 2 = 11`)
- Tangentbordsstöd (siffror, operatorer, Enter, Backspace, Esc)
- Historikrad och radera-knapp (⌫)
- Säker beräkning utan `eval`

## Kör lokalt

Öppna `index.html` i din webbläsare – klart.

## Publicera på webben (GitHub Pages)

1. Gå till repots **Settings → Pages**
2. Under *Branch*, välj `main` och mappen `/ (root)`, spara
3. Sidan blir tillgänglig på `https://mohaxaxa123-hue.github.io/mmom/`

## Filer

- `index.html` – struktur
- `style.css` – utseende
- `script.js` – logik
